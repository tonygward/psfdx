psfdx-plugins

Salesforce CLI plugins

Install, list, inspect, update, uninstall, discover and reset the plugins of the Salesforce CLI, check the digital signature of a plugin before you install it, and manage the plugin allowlist. Installing the CLI itself stays in the psfdx module.

Get started

PS> Install-Module psfdx
PS> Import-Module psfdx
PS> Get-Command -Module psfdx-plugins

There is only one PowerShell Gallery package: psfdx. Importing it loads the entire module suite, while each command retains its owning module name. These commands were in psfdx before; their names and parameters are unchanged.

Examples

PS> Get-Help Install-SalesforcePlugin -Full
PS> Get-Command -Module psfdx-plugins
PS> Get-Help Uninstall-SalesforcePlugin -Examples

Check, install and manage plugins

Installing a plugin runs code with your permissions, so the cmdlets that install, remove or relax a check support -WhatIf and ask for confirmation first.

PS> Test-SalesforcePluginSignature -Npm @salesforce/plugin-agent
PS> Install-SalesforcePlugin -Name @salesforce/plugin-agent -WhatIf
PS> Install-SalesforcePlugin -Name @salesforce/plugin-agent
PS> Get-SalesforcePlugins
PS> Get-SalesforcePluginDetails -Name @salesforce/plugin-agent

Find third-party plugins with Find-SalesforcePlugins, keep them current with Update-SalesforcePlugins, remove one with Uninstall-SalesforcePlugin, start clean with Reset-SalesforcePlugins, and control which unsigned plugins may be installed with Get-, Add- and Remove-SalesforcePluginAllowlist.

Discover every command and parameter

PowerShell's built-in help includes descriptions, parameter documentation and usage examples. For commands that invoke Salesforce CLI, the help also describes the corresponding sf command.

PS> Get-Command -Module psfdx-plugins
PS> Get-Help Install-SalesforcePlugin -Full
PS> Update-Module psfdx
