MODULE REFERENCE / psfdx-devops

psfdx-devops

DevOps Center

Manage Salesforce DevOps Center projects, work items, pipelines, stages, branches, environments and promotions, and run the beta pipeline deploys. Every cmdlet that wraps a command of the Salesforce CLI DevOps Center plugin lives here.

Get started

PS> Install-Module psfdx
PS> Import-Module psfdx
PS> Get-Command -Module psfdx-devops

There is only one PowerShell Gallery package: psfdx. Importing it loads the entire module suite, while each command retains its owning module name. These commands were in psfdx-metadata before; their names and parameters are unchanged.

Examples

PS> Get-Help Start-SalesforceDevOpsPromotion -Full
PS> Get-Command -Module psfdx-devops
PS> Get-Help Test-SalesforceDevOpsPromotion -Examples

Promote a work item through a pipeline

Every cmdlet that changes something supports -WhatIf, and the ones that deploy or delete ask for confirmation first. You need a DevOps Center org you are logged in to, passed as -TargetOrg.

PS> $items = Get-SalesforceDevOpsWorkItem -ProjectId 1Qg000000000001 -TargetOrg devops-org
PS> Test-SalesforceDevOpsPromotion -WorkItemId $items[0].id -TargetStageId 1QV000000000002 -TargetOrg devops-org
PS> Start-SalesforceDevOpsPromotion -WorkItemId $items[0].id -TargetStageId 1QV000000000002 -TargetOrg devops-org -WhatIf

The earlier beta commands that deploy a branch to a pipeline stage (Start-SalesforcePipelineDeploy, Test-SalesforcePipelineDeploy, Start-SalesforcePipelineQuickDeploy, Get-SalesforcePipelineDeployStatus and Resume-SalesforcePipelineDeploy) are in this module too, because they come from the same plugin.

Discover every command and parameter

PowerShell's built-in help includes descriptions, parameter documentation and usage examples. For commands that invoke Salesforce CLI, the help also describes the corresponding sf command.

PS> Get-Command -Module psfdx-devops
PS> Get-Help Start-SalesforceDevOpsPromotion -Full
PS> Update-Module psfdx
