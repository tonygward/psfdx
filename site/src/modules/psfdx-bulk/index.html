psfdx-bulk

Bulk API 2.0

Export, import, update, upsert and delete records in bulk with Salesforce Bulk API 2.0, then follow, resume and collect the results of the jobs. The cmdlets take a CSV and return a job you can keep following.

Part of the psfdx package, which installs every module: see the installation and update instructions. Its commands moved here from psfdx; their names and parameters are unchanged.

PS> Get-Command -Module psfdx-bulk

Export-SalesforceBulkData Exports the records of a SOQL query to a file with Bulk API 2.0 (sf data export bulk).

Syntax

Export-SalesforceBulkData -OutputFile <string> [-Query <string>] [-QueryFile <string>] [-ResultFormat <string>] [-AllRows] [-ColumnDelimiter <string>] [-LineEnding <string>] [-WaitMinutes <int>] [-TargetOrg <string>]

Parameters

-OutputFile string, required
File where records are written. Passed to sf as --output-file. Required.
-Query string
SOQL query to execute. Passed to sf as --query.
-QueryFile string
File that contains the SOQL query. Passed to sf as --query-file.
-ResultFormat string
Format to write the results. Passed to sf as --result-format. Default: csv. Valid values: csv, json.
-AllRows switch
Include records that have been soft-deleted due to a merge or delete. By default, deleted records are not returned. Adds --all-rows.
-ColumnDelimiter string
Column delimiter to be used when writing CSV output. Default is COMMA. Passed to sf as --column-delimiter. Valid values: BACKQUOTE, CARET, COMMA, PIPE, SEMICOLON, TAB.
-LineEnding string
Line ending to be used when writing CSV output. Default value on Windows is is `CRLF`; on macOS and Linux it's `LR`. Passed to sf as --line-ending. Valid values: LF, CRLF.
-WaitMinutes int
Time to wait for the command to finish, in minutes. Passed to sf as --wait. Default: 0. Range: 0 to 1440.
-TargetOrg string
Username or alias of the target org. Not required if the `target-org` configuration variable is already set. Passed to sf as --target-org.

Example

PS> Export-SalesforceBulkData -Query 'SELECT Id, Name FROM Account' -OutputFile .\accounts.csv -WaitMinutes 10 -TargetOrg myorg

Salesforce CLI

Runs sf data export bulk.

Get-SalesforceBulkResult Gets the outcome of a Bulk API 2.0 ingest job and saves its row results as CSV files (sf data bulk results).

Syntax

Get-SalesforceBulkResult -JobId <string> [-OutputDirectory <string>] [-TargetOrg <string>]

Parameters

-JobId string, required
Job ID of the bulk job. Passed to sf as --job-id. Required.
-OutputDirectory string
Folder the result files are written to. It is created if it does not exist. Defaults to the current folder. The cmdlet runs the CLI there and returns the full paths of the files it wrote.
-TargetOrg string
Username or alias of the target org. Not required if the `target-org` configuration variable is already set. Passed to sf as --target-org.

Example

PS> $r = Get-SalesforceBulkResult -JobId 750xx0000000001 -OutputDirectory .\bulk -TargetOrg myorg; if ($r.HasFailures) { Import-Csv $r.FailedFilePath }

Runs sf data bulk results.

Remove-SalesforceBulkData Deletes the records whose IDs are in a CSV file with Bulk API 2.0 (sf data delete bulk).

Syntax

Remove-SalesforceBulkData -File <string> -Object <string> [-HardDelete] [-LineEnding <string>] [-WaitMinutes <int>] [-TargetOrg <string>]

Parameters

-File string, required
CSV file that contains the IDs of the records to delete. Passed to sf as --file. Required.
-Object string, required
API name of the Salesforce object, either standard or custom, that you want to delete records from. Passed to sf as --sobject. Required.
-HardDelete switch
Delete the records permanently, without moving them to the Recycle Bin. Adds --hard-delete. The user needs the Bulk API Hard Delete permission.
-LineEnding string
Line ending used in the CSV file. Default value on Windows is `CRLF`; on macOS and Linux it's `LF`. Passed to sf as --line-ending. Valid values: LF, CRLF.
-WaitMinutes int
Time to wait for the command to finish, in minutes. Passed to sf as --wait. Default: 0. Range: 0 to 1440.
-TargetOrg string
Username or alias of the target org. Not required if the `target-org` configuration variable is already set. Passed to sf as --target-org.

Example

PS> Remove-SalesforceBulkData -File .\old-accounts.csv -Object Account -WaitMinutes 10 -TargetOrg myorg -WhatIf

Preview the delete without sending anything.

Resume-SalesforceBulkJob Resumes a Bulk API 2.0 job started without -WaitMinutes (sf data export|import|update|upsert|delete resume).

Syntax

Resume-SalesforceBulkJob -Operation <string> -JobId <string> [-WaitMinutes <int>] [-TargetOrg <string>]
Resume-SalesforceBulkJob -Operation <string> -UseMostRecent [-WaitMinutes <int>] [-TargetOrg <string>]

Parameters

-Operation string, required
The kind of bulk job to resume: Export, Import, Update, Upsert or Delete. It selects which command runs: sf data export, import, update, upsert or delete resume. Required. Valid values: Export, Import, Update, Upsert, Delete.
-JobId string, required
Job ID of the bulk job. Passed to sf as --job-id. Required unless you give -UseMostRecent.
-UseMostRecent switch, required
Resume the job that was started most recently, instead of giving -JobId. Adds --use-most-recent.
-WaitMinutes int
Time to wait for the command to finish, in minutes. Passed to sf as --wait. Default: 0. Range: 0 to 1440.
-TargetOrg string
Username or alias of the target org. Not required if the "target-org" configuration variable is already set. Passed to sf as --target-org.

Example

PS> Resume-SalesforceBulkJob -Operation Upsert -JobId 750xx0000000001 -WaitMinutes 10 -TargetOrg myorg

Salesforce CLI

Runs sf data export resume, sf data import resume, sf data update resume, sf data upsert resume, sf data delete resume.

Upsert-SalesforceBulkData Inserts or updates records from the rows of a CSV file by external ID with Bulk API 2.0 (sf data upsert bulk).

Parameters

-File string, required
CSV file that contains the IDs of the records to update or delete. Passed to sf as --file. Required.
-Object string, required
API name of the Salesforce object, either standard or custom, that you want to update or delete records from. Passed to sf as --sobject. Required.
-ExternalIdField string, required
Name of the external ID field, or the Id field. Passed to sf as --external-id. Required.
-ColumnDelimiter string
Column delimiter used in the CSV file. Passed to sf as --column-delimiter. Valid values: BACKQUOTE, CARET, COMMA, PIPE, SEMICOLON, TAB.
-LineEnding string
Line ending used in the CSV file. Default value on Windows is `CRLF`; on macOS and Linux it's `LF`. Passed to sf as --line-ending. Valid values: LF, CRLF.
-WaitMinutes int
Number of minutes to wait for the command to complete before displaying the results. Passed to sf as --wait. Default: 0. Range: 0 to 1440.
-TargetOrg string
Username or alias of the target org. Not required if the `target-org` configuration variable is already set. Passed to sf as --target-org.

Example
