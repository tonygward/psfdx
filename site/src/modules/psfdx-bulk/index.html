psfdx-bulk

Bulk API 2.0

Export, import, update, upsert and delete records in bulk with Salesforce Bulk API 2.0, then follow, resume and collect the results of the jobs. The cmdlets take a CSV and return a job you can keep following.

Get started

PS> Install-Module psfdx
PS> Import-Module psfdx
PS> Get-Command -Module psfdx-bulk

There is only one PowerShell Gallery package: psfdx. Importing it loads the entire module suite, while each command retains its owning module name. These commands were in psfdx before; their names and parameters are unchanged.

Examples

PS> Get-Help Import-SalesforceBulkData -Full
PS> Get-Command -Module psfdx-bulk
PS> Get-Help Remove-SalesforceBulkData -Examples

Bulk load, follow and collect results

Every cmdlet that changes records supports -WhatIf, and a bulk delete asks for confirmation first. Each cmdlet returns the job, so you can follow it, resume it, or collect its result files later.

PS> Import-SalesforceBulkData -File .\accounts.csv -Object Account -TargetOrg dev1 -WhatIf
PS> $job = Import-SalesforceBulkData -File .\accounts.csv -Object Account -TargetOrg dev1
PS> Get-SalesforceBulkJobStatus -JobId $job.JobId -TargetOrg dev1
PS> Get-SalesforceBulkResult -JobId $job.JobId -TargetOrg dev1

Export a query to a file with Export-SalesforceBulkData, change records from a CSV with Update-SalesforceBulkData or Upsert-SalesforceBulkData (upsert by external ID), delete them with Remove-SalesforceBulkData, and pick up a job that was left running with Resume-SalesforceBulkJob. Single-record changes and SOQL stay in the psfdx module.

Discover every command and parameter

PowerShell's built-in help includes descriptions, parameter documentation and usage examples. For commands that invoke Salesforce CLI, the help also describes the corresponding sf command.

PS> Get-Command -Module psfdx-bulk

PS> Update-Module psfdx
