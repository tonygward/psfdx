Invoke-SalesforceAgentPreview Talks to an agent in the terminal to see how it responds.

Syntax

Invoke-SalesforceAgentPreview [-ApiName <string>] [-AuthoringBundle <string>] [-ContextVariables <IDictionary>] [-ContextVariablesJson <string>] [-ApexDebug] [-UseLiveActions] [-OutputDir <string>] [-TargetOrg <string>]

Parameters

-ApiName string
API name of a published, activated agent. Use it or -AuthoringBundle, not both. Passed to sf as --api-name.
-AuthoringBundle string
API name of a local authoring bundle (an Agent Script agent in the project). Use it or -ApiName, not both. Passed to sf as --authoring-bundle.
-ContextVariables IDictionary
Context variables for the conversation as name and value pairs. Each pair is passed to sf as its own --context-variables name=value. Names are checked, and a value may not contain a double quote or line break. Cannot be used with -ContextVariablesJson. Passed to sf as --context-variables.
-ContextVariablesJson string
Context variables as a JSON string, for example '{"order":"1001"}'. It must be valid JSON. On Windows the CLI's .cmd launcher cannot take an argument with double quotes, which JSON always has, so this does not work there: use -ContextVariables. Cannot be used with -ContextVariables. Passed to sf as --context-variables-json.
-ApexDebug switch
Show Apex debug logs of the agent's actions. Adds --apex-debug.
-UseLiveActions switch
Run the real actions of the agent, which can change data. Only for an authoring bundle. Adds --use-live-actions.
-OutputDir string
Folder to save the conversation transcript and traces to. Passed to sf as --output-dir.
-TargetOrg string
Username or alias of the target org. Not required if the `target-org` configuration variable is already set. Passed to sf as --target-org.

Example

PS> Invoke-SalesforceAgentPreview -ApiName Service_Agent -TargetOrg dev1

Chat with a published agent.

Salesforce CLI

Runs sf agent preview.

New-SalesforceAgentAuthoringBundle Generates an authoring bundle (Agent Script) for an agent (sf agent generate authoring-bundle).

Syntax

New-SalesforceAgentAuthoringBundle -Name <string> [-ApiName <string>] [-Spec <string>] [-NoSpec] [-OutputDir <string>] [-ForceOverwrite] [-TargetOrg <string>]

Parameters

-Name string, required
Name (label) of the authoring bundle; if not specified, you're prompted for the name. Passed to sf as --name. Required.
-ApiName string
API name of the new authoring bundle; if not specified, the API name is derived from the authoring bundle name (label); the API name can't exist in the org. Passed to sf as --api-name.
-Spec string
Path to the agent spec YAML file. If you don't specify the flag, the command provides a list that you can choose from. Use the --no-spec flag to skip using an agent spec entirely.

-OutputDir string
Directory where the authoring bundle files are generated. Passed to sf as --output-dir.
-ForceOverwrite switch
Overwrite an existing authoring bundle of that name without asking. Without it the CLI refuses to replace one. Adds --force-overwrite.
-TargetOrg string
Username or alias of the target org. Not required if the `target-org` configuration variable is already set. Passed to sf as --target-org.

Example

PS> New-SalesforceAgentAuthoringBundle -Name 'Service Agent' -ApiName Service_Agent -Spec specs/agentSpec.yaml -TargetOrg my-org

New-SalesforceAgentDataLibrary Creates an Agentforce Data Library, the knowledge an agent is grounded in.

Syntax

New-SalesforceAgentDataLibrary -Name <string> -DeveloperName <string> -SourceType <string> [-Description <string>] [-IndexMode <string>] [-ContentFields <string[]>] [-DataCategoryIds <string[]>] [-DataCategoryNames <string[]>] [-PrimaryIndexField1 <string>] [-PrimaryIndexField2 <string>] [-RetrieverId <string>] [-WaitMinutes <int>] [-TargetOrg <string>]

Parameters

-Name string, required
Name (label) of the library. Passed to sf as --name. Required.
-DeveloperName string, required
API name of the library. Passed to sf as --developer-name. Required.
-SourceType string, required
Where the library's content comes from. Valid values: sfdrive, knowledge, retriever. Passed to sf as --source-type. Required.
-Description string
Description of the library. Passed to sf as --description.
-IndexMode string
How the content is indexed. Valid values: basic, enhanced. Passed to sf as --index-mode.
-ContentFields string[]
Knowledge fields to index. For a knowledge library. The values are joined with commas and passed as one --content-fields.
-DataCategoryIds string[]
IDs of the data categories to include. For a knowledge library. The values are joined with commas and passed as one --data-category-ids. Use it or -DataCategoryNames, not both.
-DataCategoryNames string[]
Names of the data categories to include. Qualified names such as Group_API_Name.Category, for a knowledge library. The values are joined with commas and passed as one --data-category-names. Use it or -DataCategoryIds, not both.
-PrimaryIndexField1 string
First field of the primary index. For a retriever library. Passed to sf as --primary-index-field1.
-PrimaryIndexField2 string
Second field of the primary index. For a retriever library. Passed to sf as --primary-index-field2.
-RetrieverId string
ID of the retriever. For a retriever library. Passed to sf as --retriever-id.
-WaitMinutes int
Number of minutes to wait for the library to be created. Passed to sf as --wait.
-TargetOrg string
Username or alias of the target org. Not required if the `target-org` configuration variable is already set. Passed to sf as --target-org.

Example

PS> New-SalesforceAgentDataLibrary -Name 'Product Manuals' -DeveloperName Product_Manuals -SourceType sfdrive -WaitMinutes 5 -TargetOrg dev1
