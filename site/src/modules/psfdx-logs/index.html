Convert-SalesforceDebugLog Converts the text of a debug log into one object per line (in development).

Syntax

Convert-SalesforceDebugLog -Log <string>

Parameters

-Log string, required
The log text to convert. Accepts pipeline input. Required.

Example

PS> Get-SalesforceDebugLogs -Last 1 -Raw -TargetOrg dev1 | Convert-SalesforceDebugLog | Select-Object -First 20

The first twenty log lines as objects.

Disable-SalesforceDebugLogging Deletes a trace flag to stop debug logging (sf apex trace delete).

Syntax

Disable-SalesforceDebugLogging -TraceId <string> [-TargetOrg <string>]

Parameters

-TraceId string, required
ID of the trace flag to delete. Passed to sf as --trace-flag-id. Required. Alias: Id, TraceFlagId. Accepts input from the pipeline by property name.
-TargetOrg string
Username or alias of the target org. Not required if the `target-org` configuration variable is already set. Passed to sf as --target-org.

Example

PS> Get-SalesforceDebugLogging -TargetOrg myorg | Disable-SalesforceDebugLogging -TargetOrg myorg -WhatIf

Enable-SalesforceDebugLogging Turns on debug logging for a user, Apex class or Apex trigger by creating a trace flag.

Syntax

Enable-SalesforceDebugLogging -TracedEntityId <string> -DebugLevel <string> [-LogType <string>] [-Duration <int>] [-TargetOrg <string>]
Enable-SalesforceDebugLogging -Username <string> -DebugLevel <string> [-LogType <string>] [-Duration <int>] [-TargetOrg <string>]
Enable-SalesforceDebugLogging -ApexClass <string> -DebugLevel <string> [-LogType <string>] [-Duration <int>] [-TargetOrg <string>]
Enable-SalesforceDebugLogging -ApexTrigger <string> -DebugLevel <string> [-LogType <string>] [-Duration <int>] [-TargetOrg <string>]

Parameters

-TracedEntityId string, required
ID of the user, Apex class, or Apex trigger to trace. Passed to sf as --traced-entity-id. Required in the Id parameter set.
-Username string, required
User name of the user to trace. psfdx looks up the user's ID and passes it as --traced-entity-id. Required in the Username parameter set.
-ApexClass string, required
Name of the Apex class to trace. psfdx looks up its ID and passes it as --traced-entity-id. Required in the ApexClass parameter set.
-ApexTrigger string, required
Name of the Apex trigger to trace. psfdx looks up its ID and passes it as --traced-entity-id. Required in the ApexTrigger parameter set.
-DebugLevel string, required
Developer name of an existing debug level to apply. Passed to sf as --debug-level. Required.
-LogType string
Type of trace flag to create. Passed to sf as --log-type. Valid values: DEVELOPER_LOG, USER_DEBUG.
-Duration int
Duration, in minutes, before the trace flag expires. Maximum is 1440 (24 hours). Passed to sf as --duration. Range: 1 to 1440.
-TargetOrg string
Username or alias of the target org. Not required if the `target-org` configuration variable is already set. Passed to sf as --target-org.

Example

PS> Enable-SalesforceDebugLogging -Username me@example.com -DebugLevel SFDC_DevConsole -Duration 60 -TargetOrg dev1

Trace one user for an hour.

Salesforce CLI

Runs sf apex trace create.

Export-SalesforceDebugLogs Saves the most recent debug logs to files.

Syntax

Export-SalesforceDebugLogs [-Limit <int>] [-OutputFolder <string>] [-TargetOrg <string>]

Parameters

-Limit int
How many logs to save, taken from the start of the list the CLI returns. Default 50. Default: 50.
-OutputFolder string
Folder to write the .log files to. It must exist. Defaults to the current folder.
-TargetOrg string
Username or alias of the org to read the logs from. If omitted, the Salesforce CLI uses the default target org.

Example

PS> Export-SalesforceDebugLogs -Limit 5 -OutputFolder .\logs -TargetOrg dev1

Save the five newest logs.

Get-SalesforceDebugLogs Fetches one debug log, or the newest few, from an org.

Syntax

Get-SalesforceDebugLogs [-OutputDir <string>] [-LogId <string>] [-Last <int>] [-Raw] [-TargetOrg <string>]

Parameters

-OutputDir string
Directory for saving the log files. Passed to sf as --output-dir.
-LogId string
ID of the specific log to display. Passed to sf as --log-id.
-Last int
Fetch this many of the newest logs. Passed as --number. Use instead of -LogId.
-Raw switch
Return the log text as the CLI prints it.
-TargetOrg string
Username or alias of the target org. Not required if the `target-org` configuration variable is already set. Passed to sf as --target-org.

Example

PS> Get-SalesforceDebugLogs -Last 1 -Raw -TargetOrg dev1

The newest log, as text.

Get-SalesforceFlowInterviews Lists flow interviews, for example the ones that failed.

Syntax

Get-SalesforceFlowInterviews [-Type <string>] [-After <datetime>] [-Limit <int>] [-TargetOrg <string>]

Parameters

-Type string
Interview status to list: Error, Paused, Running, Completed, VersionPaused, Autosaved, Expired, or All (the default). Default: All. Valid values: Error, Paused, Running, Completed, VersionPaused, Autosaved, Expired, All.
-After datetime
Only interviews created at or after this time.
-Limit int
SOQL query to execute. Passed to sf as --query. Default: 200.
-TargetOrg string
Username or alias of the target org. Not required if the `target-org` configuration variable is already set. Passed to sf as --target-org.

Example

PS> Get-SalesforceFlowInterviews -Type Error -After (Get-Date).AddDays(-1) -TargetOrg prod

Flow errors in the last day.

Watch-SalesforceDebugLogs Streams debug logs from an org to the terminal.

Syntax

Watch-SalesforceDebugLogs [-DebugLevel <string>] [-SkipTraceFlag] [-TargetOrg <string>]

Parameters

-DebugLevel string
Debug level to set on the DEVELOPER_LOG trace flag for your user. Passed to sf as --debug-level.
-SkipTraceFlag switch
Skip trace flag setup. Assumes that a trace flag and debug level are fully set up. Adds --skip-trace-flag.
-TargetOrg string
Username or alias of the target org. Not required if the `target-org` configuration variable is already set. Passed to sf as --target-org.

Example

PS> Watch-SalesforceDebugLogs -DebugLevel SFDC_DevConsole -TargetOrg dev1

Follow the logs of the org.
