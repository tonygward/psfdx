psfdx-packages

Package management

Create, version, promote, install and track first- and second-generation packages.

Get started

Install-Module psfdx
Import-Module psfdx
Get-Command -Module psfdx-packages

There is only one PowerShell Gallery package: psfdx. Importing it loads the entire module suite, while each command retains its owning module name.

Examples

Get-Command -Module psfdx-packages
Get-Help Get-SalesforcePackageVersions -Full

Discover every command and parameter

PowerShell's built-in help includes descriptions, parameter documentation and usage examples. For commands that invoke Salesforce CLI, the help also describes the corresponding sf command.
