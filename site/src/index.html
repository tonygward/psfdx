A simpler, more intuitive way to work with Salesforce.

psfdx brings the power of the Salesforce CLI into PowerShell, making everyday Salesforce development, administration and automation easier. Less time remembering CLI syntax. More time getting things done.

  • | pipeline

    Built around PowerShell

    Familiar commands and structured objects, so you can filter, sort, export and pipe results like any other PowerShell data.

  • win · mac · linux

    Runs everywhere

    PowerShell 7 on Windows, macOS and Linux. Windows PowerShell 5.1 is supported too.

  • -Verbose

    Nothing hidden

    psfdx wraps the official Salesforce CLI, and -Verbose shows the exact sf command it runs, so you can always see what happened.
