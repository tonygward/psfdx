A simpler, more intuitive way to work with Salesforce.

psfdx brings the power of the Salesforce CLI into PowerShell, making everyday Salesforce development, administration and automation easier.

  • | pipeline

    Objects, not JSON

    Every command returns real PowerShell objects, not text to parse. Pipe them straight into Where-Object, Sort-Object, Group-Object or Export-Csv. No jq, no string handling.

  • win · mac · linux

    Runs everywhere

    PowerShell 7 on Windows, macOS and Linux. Windows PowerShell 5.1 is supported too.

  • Get-Command · Get-Help

    Everything is discoverable

    Get-Command and Get-Help are all you need to find every command and every parameter, with examples.

    PS> Get-Command -Module 'psfdx*'
PS> Get-Help Deploy-SalesforceMetadata -Examples

Comparison: Export accounts to CSV

Both examples do the same job, but the psfdx version is easier to read. psfdx returns PowerShell objects, so you can pipe the results straight into tools like Sort-Object and Group-Object.
