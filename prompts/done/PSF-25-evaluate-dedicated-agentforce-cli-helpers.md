# PSF-25: Evaluate dedicated Agentforce CLI helpers

**Tracking issue:** https://github.com/tonygward/psfdx/issues/110

Generated by Matrix from the tracking issue when the card was picked up, because no prompt file existed and the issue had enough detail. The issue text below is the specification.

## Objective
Close the most valuable new-feature coverage gap in psfdx while keeping its existing modules focused.

## Scope
- Map official stable Salesforce CLI Agentforce/agent commands, including available agent creation, authoring, validation, testing and preview workflows.
- Distinguish stable features from beta/developer-preview commands and avoid promising unsupported operations.
- Propose/implement a small, coherent `psfdx-agentforce` module only for stable, useful commands; document optional CLI plugin prerequisites.
- Support structured PowerShell output, `-TargetOrg`, error mapping and safe `ShouldProcess` use.

## Acceptance criteria
- Documented command-to-cmdlet parity matrix with the CLI/plugin version used.
- New public cmdlets exported in manifest, registered in `modules.ps1`, and documented in README/CHANGELOG.
- No beta APIs treated as stable by default; all org-modifying operations guarded appropriately.
- PowerShell 5.1 and 7 compatibility.

## Tests
- Pester command generation, JSON mapping, plugin absent, invalid arguments and failures.
- CLI help/availability verification; optional sandbox-backed smoke tests.
