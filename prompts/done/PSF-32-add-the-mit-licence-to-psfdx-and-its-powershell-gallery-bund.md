# PSF-32: Add the MIT licence to psfdx and its PowerShell Gallery bundle

**Tracking issue:** https://github.com/tonygward/psfdx/issues/149

Generated by Matrix from the tracking issue when the card was picked up, because no prompt file existed and the issue had enough detail. The issue text below is the specification.

## Objective

Apply the MIT licence to psfdx and make the licence visible in the PowerShell Gallery package. This supports AUTO-11 (#123).

## Scope

Add the repository licence and update README and Gallery package metadata. Check copyright ownership and preserve inherited notices where applicable.

## Checklist

- Confirm the copyright holder for the code in the bundle. If any code was inherited from ZenInternet or another contributor, verify its licence or the rights holder's permission and retain any required notices.
- Add the standard [MIT licence text](https://opensource.org/license/mit) in a root `LICENSE` file with the appropriate copyright notice.
- Set `PrivateData.PSData.LicenseUri` in `psfdx/psfdx.psd1` to the public URL for the repository's licence file.
- Add a short licence section to the README linking to `LICENSE`.
- Build the Gallery bundle and verify the generated manifest carries `LicenseUri` and the bundle includes the licence text. Verify the GitHub release ZIP includes it as well. Update package assembly if needed.

## Acceptance criteria

The repository identifies MIT as its licence, required notices ship with both distribution formats, and the Gallery bundle's licence URL resolves to the repository's MIT licence after merge.

## Tests

Build the Gallery bundle and verify the included licence and generated `LicenseUri`. Verify that the release ZIP includes the licence.
