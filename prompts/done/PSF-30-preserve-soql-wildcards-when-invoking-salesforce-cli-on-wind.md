# PSF-30: Preserve SOQL wildcards when invoking Salesforce CLI on Windows

**Tracking issue:** https://github.com/tonygward/psfdx/issues/147

Generated by Matrix from the tracking issue when the card was picked up, because no prompt file existed and the issue had enough detail. The issue text below is the specification.

## Objective

Restore ordinary SOQL wildcard queries on Windows after the 0.8.7 executor change.

## Regression

psfdx 0.8.7 rejects any argument containing `%` when the Salesforce CLI resolves to `sf.cmd`. This blocks valid SOQL wildcard queries before they reach Salesforce CLI.

```powershell
Select-SalesforceRecords -Query "SELECT Id FROM Account WHERE Name LIKE 'Acme%'" -TargetOrg my-org
```

The rejection follows from the [query wrapper](https://github.com/tonygward/psfdx/blob/main/psfdx/psfdx.psm1#L324-L350) and [PSF-26 executor change](https://github.com/tonygward/psfdx/pull/145). The existing end-to-end argv test skips Windows. The rejection was verified by code inspection.

## Scope

Update native argument handling in `psfdx-shared/Invoke-Salesforce.ps1` for Windows `sf.cmd` calls. Keep the public `Select-SalesforceRecords` interface, argument boundaries and verbose secret redaction.

## Acceptance criteria

- Preserve `%` literally inside SOQL query arguments, including prefix, suffix and infix wildcards, on Windows installations where `sf` resolves to `sf.cmd`.
- Preserve argument boundaries and keep shell metacharacters and environment-variable syntax from being evaluated as code. Keep verbose secret redaction.
- Exercise a public cmdlet through the Windows invocation path with an offline argv-capture fixture. Cover PowerShell 7 and Windows PowerShell 5.1, including a literal `%NAME%` and arguments containing spaces.
- Preserve result formats and existing cross-platform behavior. Update the changelog.

Related audit: #112.

## Tests

Add an offline Windows argv-capture regression test exercised through `Select-SalesforceRecords` on both PowerShell 7 and Windows PowerShell 5.1. Cover prefix, suffix and infix wildcards, a literal `%NAME%`, shell metacharacters, and arguments with spaces.
