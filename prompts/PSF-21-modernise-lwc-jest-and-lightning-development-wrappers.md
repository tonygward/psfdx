# PSF-21: Modernise LWC Jest and Lightning development wrappers

**Tracking issue:** https://github.com/tonygward/psfdx/issues/106

Generated by Matrix from the tracking issue when the card was picked up, because no prompt file existed and the issue had enough detail. The issue text below is the specification.

## Objective
Bring existing LWC development helpers into alignment with supported current Salesforce CLI and Lightning development tooling.

## Scope
- Audit `New-SalesforceJestTest` in `psfdx-development/psfdx-development.psm1` (currently `sf force lightning lwc test create`), replacing any removed/unsupported legacy invocation with a supported test scaffold workflow while retaining the cmdlet.
- Audit `Install-SalesforceLwcDevServer` and `Start-SalesforceLwcDevServer` against the current `@salesforce/plugin-lightning-dev` command surface; use supported app/component/site modes where appropriate.
- Keep `Install-SalesforceJest`, test/watch/debug commands aligned with supported Jest workflows.

## Acceptance criteria
- Existing cmdlets either work against stable CLI or fail with clear actionable error and supported alternative.
- Support newer preview modes only where current official plugin documentation confirms them.
- Preserve public PowerShell API where possible; document any breaking changes.
- Update manifest exports (if new commands), README and CHANGELOG.

## Tests
- Pester for exact CLI arguments, paths with spaces, missing plugin, and absent test files.
- CLI help/smoke tests (non-destructive) for command availability.
- Tests work under Windows PowerShell 5.1 and PowerShell 7.
